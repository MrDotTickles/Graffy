WELCOME TO GRAFFY

One app. No technical setup.

Make scientific graphs, analyze data, and export figures.

Graffy download website and installation help →

On Windows

  1. Double-click Start Graffy.vbs beside this guide.
  2. If Graffy is not installed, follow the installer. Click Install, then Finish.
  3. After installing, open Graffy from your desktop or Start menu. No Python window is needed.

On a Mac

Download the Mac disk image for your chip from the official downloads. Open it, drag Graffy into Applications, then open Graffy from Applications. App downloads appear after the first packaged release is published.

Install or update Graffy for Windows using the installer in this folder.

Inside the app

Choose Import my data, Open a saved project, Try an example, or Start a blank worksheet. Select columns, choose 2 Create chart, then 3 Export graph. Use Edit chart for titles, labels, and style.

Updating is simple. Graffy tells you when a new version is ready. Download it in the app, save your work, close Graffy, and run the new installer. On Mac, replace the app in Applications.

Development tools are in scripts. Ordinary app users can ignore them.

Current preview builds are unsigned; Windows or macOS may display a publisher warning. Installation details.
