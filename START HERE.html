WELCOME TO GRAFFY

One app. No technical setup.

Make scientific graphs, analyze data, and export figures.

Graffy download website and installation help →

On Windows

  1. Download the latest Windows installer.
  2. Open it and follow the setup prompts.
  3. After installing, open Graffy from your desktop or Start menu. No Python window is needed.

On a Mac

Download the Mac disk image for your chip from the official downloads. Open it, drag Graffy into Applications, then open Graffy from Applications.

Inside the app

Choose Import data, open a saved project, or try the built-in example. Use Create chart and Export graph when your data is ready.

Updating is simple. Use Help → Check for Updates or View update in the app. Download it, save your work, close Graffy, and run the new installer. On Mac, replace the app in Applications.

Working on the code? In a configured Git checkout, Start Graffy.vbs opens your current source. The Start menu opens the installed app.

Current preview builds are unsigned; Windows or macOS may display a publisher warning. Installation details.
